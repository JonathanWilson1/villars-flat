# Le Bristol A46 — Villars-sur-Ollon

Static site for the Interhome-let flat (CH1884.783.20). Book buttons go to the My Rent link.

- Summer/winter toggle: `#summer` / `#winter` in the link (shareable; `?season=` also read), else saved choice, else by month (Oct–Apr = winter).
- Pages: `index.html`, `aiglon-college-accommodation.html`, `beau-soleil-accommodation.html` (one SEO page per school) (shared styles in `guide.css`).
- Photos: own (July 2025), Interhome listing (`img/ih-*`), Wikimedia Commons CC BY-SA (`img/cc-*`, credited in footer — keep credits if images stay).
- Videos: click-to-load YouTube (no-cookie) embeds, list in the `VIDEOS` object.
- Hosted on GitHub Pages: https://jonathanwilson1.github.io/villars-flat/ (DOMAIN constant in `tools/i18n.py`; change it there and re-render if a custom domain is added). Submit `sitemap.xml` in Search Console.

Preview: `python3 -m http.server 8742 --bind 127.0.0.1`

## Languages
English at the root; fr, de, it, es, pt, nl, ar (RTL), ru, zh under `/<lang>/`, generated — don't hand-edit them.
After editing an English page: `python tools/i18n.py extract` (lists missing strings per language), add translations to `i18n/<lang>.json` (keys are hashes of the English), then `python tools/i18n.py render` (also refreshes hreflang, language switcher and `sitemap.xml`). Needs `beautifulsoup4`.
School pages are generated by a script; if regenerated, re-run render.
